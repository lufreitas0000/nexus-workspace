# Nexus Workspace

The data state repository and immutable Knowledge Garden for the Nexus Engine.

This repository stores the raw inputs, structured AST outputs, and synthesized Markdown notes produced by the `nexus-engine` pipeline. It is intentionally decoupled from the engine's source code to allow independent versioning (via `git` and `DVC`) of your personal knowledge base.

## Directory Structure

* `/raw/`: Immutable source files (PDFs, arXiv tarballs). Managed by DVC.
* `/raw_figures/`: High-resolution PNG crops extracted from PDFs.
* `/garden/`: Obsidian-compatible Markdown files holding the extracted content and synthesized atomic concepts.
* `/ledger/`: Append-only JSONL files used for auditing and offline database reconstruction.
* `nexus.db`: The SQLite database containing the citation graph and mutable operational metadata (ignored in version control).

**Warning:** Do not manually edit the YAML frontmatter in `/garden/` files, as these represent immutable provenance state generated by the engine.
