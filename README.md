# Nexus Workspace

The data state repository and immutable Knowledge Garden for the Nexus Engine.

This repository stores the raw inputs, intermediate build stages, and synthesized Markdown notes produced by the `nexus-engine` pipeline. It is decoupled from the engine's source code to allow independent versioning (via `git` and `DVC`) of your personal knowledge base.

## Directory Structure

* `/raw/`: Immutable source files (PDFs, arXiv tarballs). Managed by DVC.
* `/books/<slug>/`: Intermediate compilation staging for `book_studio` (e.g. `00_raw` to `06_compiled`).
* `/garden/`: Obsidian-compatible Markdown files holding the extracted content, enhanced figures, solutions, and synthesized atomic concepts. Only polished artifacts are published here.
* `/ledger/`: Append-only JSONL files used for auditing, tracking stubs, and offline database reconstruction.
* `/exports/kindle/`: Generated EPUB and MOBI files for delivery.
* `/state/`: Ephemeral state ledgers for long-running workflows.

**Warning:** Do not manually edit the YAML frontmatter in `/garden/` files, as these represent immutable provenance state generated by the engine.
